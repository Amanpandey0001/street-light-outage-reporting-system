# Street Light Outage and Dark Spot Reporting System

A front-end coursework project for reporting street-light outages and viewing repair status. The interface brings together report submission, a status dashboard, basic insights, and a helpline page.

## Features

- Submit an outage report with location and issue details.
- View reported, under-repair, and repaired items on a dashboard.
- Review summary counts and basic insights.
- Find the helpline information page.
- Store demo reports in the browser using localStorage.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage for demo data

## Run locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Start index.html with the Live Server extension, or serve the folder with any local static web server.
4. Use the navigation links to open Report Outage, Repair Status, Insights, and Helpline.

## Project structure

- index.html: Home page
- report.html: Outage report form
- dashboard.html: Repair status dashboard
- insights.html: Summary and insights
- helpline.html: Helpline information
- css/: Page stylesheets
- js/: Demo data and page behaviour

## Demo data and limitations

The project is a static front-end demonstration. Initial reports are sample data, and changes are stored only in the current browser's localStorage; they are not sent to a municipal service or shared with other users. Clearing browser storage resets the local demo data. No backend, authentication, or live repair workflow is included.
